- **Agent infrastructure:** multi-agent deliberation, skill bundles, and dev pipelines that hand work between people, LLMs and Claude Code.
- **Agent economies:** x402 micropayments and an agent-native prediction market protocol.
- **Guardrails:** tooling that makes agents back every success claim with evidence.
